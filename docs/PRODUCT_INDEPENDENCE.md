# Product independence

**Locus** (repository `coderag`, transitional packages `@sylphx/coderag` / `@sylphx/coderag-mcp`)
is an **independent product**.

This repository is the only source of truth for marketplace listing, release train,
package/CLI/MCP/SDK contracts, docs, tests, and stars.

- No multi-product monorepo shipping of instruments
- No `SylphxAI/instruments` authority (retired)
- Composition with siblings (Citra, Iris, Cue, Prism, Spine, Lookout) is via **public contracts** only

Company private thin map (internal): `SylphxAI/portfolio`.
